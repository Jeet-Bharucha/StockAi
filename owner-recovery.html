🔐 Restore your private StockAI account

Only for the private owner deployment. To use this page, first set a temporary OWNER_SETUP_KEY (at least 32 random bytes) in Render → StockAI (Main) → Environment and wait for deployment. Never send the key to anyone. Remove it from Render once you've logged in.

This sets a new MongoDB login password. If your account already exists, it keeps the same account, portfolio and watchlist. If the account was only saved in your old browser, it creates the owner's MongoDB account.

This is different from the browser's site-access password. Your account password and setup key are sent only to your StockAI server over HTTPS. Do not put them in GitHub.
